# CANÁRIO AMARELO BIM · fluxo passo a passo

Speckle Automate para resumo de objetos e relatório assistido.

## 1. RECEBER VERSÃO BIM

A automação recebe a versão do modelo publicada no Speckle.

## 2. LER OBJETOS

Coletar uma amostra limitada e contar tipos de objetos.

## 3. MONTAR RESUMO

Preparar um resumo textual dos dados extraídos do modelo.

## 4. GERAR ANÁLISE

Enviar o resumo ao provedor OpenAI quando configurado.

## 5. PUBLICAR RELATÓRIO

Produzir relatórios HTML e Markdown para revisão humana.

## Resultado e limites

Relatório assistido por IA sobre amostra do modelo. Não substitui auditoria BIM nem validação de engenharia.
